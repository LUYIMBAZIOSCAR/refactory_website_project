# Refactory Academy Website Clone

A modern and responsive frontend clone of the Refactory Academy website built using **HTML**, **CSS**, and **JavaScript**.

Refactory Academy is a skilling academy that offers online technology courses for all technology enthusiasts 

This project was created to practice and improve frontend web development skills by recreating a professional educational technology website UI.

---

#  Live Features

##  Responsive Navigation
- Fully responsive navbar
- Hamburger menu for mobile devices
- Dropdown courses menu
- Animated dropdown arrow

---

##  Hero Section
- Full-width hero banner
- Background image slider
- Centered content
- Call-to-action buttons

---
